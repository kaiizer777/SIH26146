What this system is. An air-gapped, offline Bitcoin transaction-traffic surveillance engine for NTRO. It ingests bulk CSV / JSON / XML transaction+network exports, correlates the network layer (IP, ASN, geolocation via local MaxMind GeoLite2) against the blockchain layer (wallet, TXID, input/output graph) in Neo4j, then applies ML to cluster entities, flag anomalies, catch peeling chains and CoinJoin mixing, and score risk — with a full court-admissible explainability trail. Stack: FastAPI + Celery/Redis + PostgreSQL 16 + Neo4j 5.26 (GDS) + PyTorch 2.4.1 CPU / PyG 2.6.1 + Next.js 16. Zero cloud egress.

KDo-Not-Claim — binding correctionsFacts, not opinion
1
There is no histogram on the anomaly slider.
The sidebar has a range input and 4 preset pills. Nothing else. Never call it a distribution chart — a judge who opens devtools will catch it.
2
Counts are 15,873 — not 17,020. Subgraphs are 100 — not 500.
Internal docs claim 17,020 evidence trails and 500 GNN subgraphs. The shipped JSON artifacts hold 15,873 and 100. Use the artifact numbers or regenerate first.
3
"RISK VECTOR" and "Import Batch" are wrong labels.
The UI says Risk Verdict and Ingest Batch. Both strings are absent from the source.
4
The 4 attention-head bars have hardcoded fallbacks.
Without a live head_attentions payload they render constants 0.91 / 0.84 / 0.78 / 0.65. Same for the 18×18 matrix, which self-generates when absent and shows a Pre-LN MHSA Saliency badge. Check the network tab before claiming live weights.
5
The top-bar counters have fallback constants.
With no backend, the UI still shows 15,873 / 103 / 10 / 3,112 / 12,648. Verify the API is live before quoting any count aloud.
6
Demo order matters: explore first, ingest last.
A fresh wallet is deliberately provisional — explainability panels show honest placeholders. Drill into an already-indexed critical wallet before uploading, or the demo looks broken when it's working as designed.
7
CoinJoin 100% is in-harness recall, not field accuracy.
The repo explicitly bans inflated claims; published methods sit at 89.2% RF / 87.5% BlockSci. Peeling 97.2% recall is the honest figure.
8
The Sec 65B dossier is generated client-side.
Web Crypto SHA-256 in the browser. There is no backend dossier endpoint. Say "exported from the dashboard", never "generated by our dossier service".
9
Don't lead with a convergence story, and don't name the legacy models as production.
FT-Transformer checkpoint records epochs_trained=1 with zero loss — its evaluation metrics are real, the training log is thin. The autoencoder and GraphSAGE are legacy fallbacks; the transformers are what ship.
